## Code
### Submenus
For those willing to implement their own submenus, ensure the following exists:
- A menu graphic in `assets/images/navButtons` with at least a static and selected frame. These frames must be around 175 by 125 pixels in size.
- A substate.
- And an entry in both `menuEntries` (with the name of the substate, which much match the graphic) and `menuXPositions` for the left-right position. I know it's pretty bad but it may be changed soon.
